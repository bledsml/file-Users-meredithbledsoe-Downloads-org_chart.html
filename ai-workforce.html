How it runs

No new software to buy — each agent is a Claude session with a schedule and a scope.

Scheduled agents

Daily and weekly roles run as scheduled routines that wake up, do the work, and email or push-notify only when something needs you — exactly how the grooming watcher behaves today.

Shared memory

Agents read and write a small set of Drive docs — property ledger, target-company list, venture notes — so the chief of staff can brief across departments without re-asking you.

Agents draft, watch, and flag; they don't send money, apply to jobs, or book anything without your sign-off. Escalations arrive through the morning brief.

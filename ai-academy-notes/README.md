# 🎓 AI Academy Notes

Personal notes from the AI Academy — one place for session notes, key
takeaways, resources, and terminology.

## Structure

```
ai-academy-notes/
├── README.md                  ← you are here
├── glossary.md                ← running list of AI terms & definitions
├── sessions/                  ← one note file per session/class
│   └── 2026-08-12-example-session.md
├── templates/
│   └── session-note.md        ← copy this to start a new session note
└── resources/
    └── links.md               ← articles, videos, papers, tools
```

## How to use

1. **Before/during a session:** copy `templates/session-note.md` into
   `sessions/` and name it `YYYY-MM-DD-topic.md` (dated names keep the
   folder sorted chronologically).
2. **After a session:** fill in the takeaways and action items while
   they're fresh.
3. **New terms:** add them to `glossary.md` so definitions live in one
   place instead of scattered across session notes.
4. **Useful links:** drop them in `resources/links.md` with a one-line
   note on why they're worth revisiting.

# Glossary

Running list of AI terms, alphabetical. Add new ones as you meet them.

| Term | Definition |
|------|------------|
| LLM (Large Language Model) | A model trained on large amounts of text to predict and generate language (e.g., Claude, GPT). |
| Prompt | The input text you give a model to get a response. |
| Token | The unit of text a model reads/writes — roughly ¾ of a word in English. |
